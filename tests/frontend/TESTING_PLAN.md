# MindGuard Frontend Testing & Build Guide

This directory contains frontend testing guidelines for the React 18 + Vite + Tailwind application located in `client/`.

## Running Frontend Production Build Check
To verify that all TypeScript types, React JSX templates, and Tailwind styles compile without errors:

```bash
cd client
npm run build
```

## Running Development Server
To start the Vite development server on `http://localhost:5173`:

```bash
cd client
npm run dev
```
