This project aims to develop an intelligent conversational AI chatbot to provide mental health support. Mental health is a worldwide issue. Many people hesitate to seek professional help due to the stigma associated with it. There is a cost and a lack of access to professional support in dealing with mental health issues of concerned individuals. An intelligent conversational chatbot can provide judgment-free support, capable of understanding and responding to mental health concerns. This project aims to interpret users intent, provide personalized self-help content, and detect suicidal thought situations. The preferred technologies include NLP models and libraries, Python (Flask / Django) for backend services, ReactJS for web frontend interface, MongoDB / PostgreSQL / Firebase for database management.
